# Linear Algebra Explorations

Jupyter notebooks implementing matrix algorithms from scratch, exploring unconventional approaches to classical linear algebra problems.

## Notebooks

| Notebook | Description |
|----------|-------------|
| `matrix_multiplication_using_2D_Polynomials.ipynb` | Matrix multiplication via 2D FFT — transform matrices into polynomials, multiply in the frequency domain, and transform back |
| `determinant_in_n^log(n).ipynb` | Divide-and-conquer determinant using the Schur complement, achieving sub-cubic complexity |
| `Trace_recursive_of_product_of_matrices.ipynb` | Computes Tr(AB) recursively by splitting into quadrants, avoiding the full matrix product |
| `gaussian_elemination_with_fractions.ipynb` | Integer-only Gaussian elimination using LCM-based row operations for exact rational results |
